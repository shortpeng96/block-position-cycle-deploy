Block Position Cycle 발표 대시보드 실행 방법

1. ZIP 파일을 원하는 폴더에 모두 압축 해제합니다.
2. 압축 해제한 폴더 안의 START_APP.bat 파일을 더블클릭합니다.
3. 첫 실행에서는 필요한 라이브러리를 자동으로 설치하므로 인터넷 연결이 필요합니다.
4. 설치가 끝나면 브라우저에서 대시보드가 열립니다.

필수 조건
- Windows 10 또는 11
- Python 3.10 또는 3.11 (64비트)

문제가 생기면
- Python이 없다는 메시지가 나오면 Python 3.11 64비트를 설치한 뒤 START_APP.bat를 다시 실행합니다.
- 브라우저가 자동으로 열리지 않으면 주소창에 http://localhost:8501 을 입력합니다.
- 실행 창은 대시보드를 사용하는 동안 닫지 않습니다.
