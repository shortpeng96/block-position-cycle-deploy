이 폴더는 김민규의 Block Position Cycle 미니프로젝트 최종 작업본이다.

먼저 다음 파일을 순서대로 읽어줘.

1. AGENTS.md
2. 00_먼저_읽으세요.md
3. Predicting 'Block Position Cycle'_0_overview.ipynb
4. streamlit_app.py

그다음 아래 작업을 먼저 수행해줘.

1. 폴더 구조와 streamlit_app.py의 상대경로가 정상인지 확인
2. requirements.txt의 라이브러리가 현재 환경에 설치됐는지 확인
3. streamlit_app.py 문법 검사
4. Streamlit AppTest로 첫 화면에 예외가 없는지 확인
5. 가능하면 앱을 실행하고 localhost 화면 확인

중요한 논리는 다음과 같다.

- 사전 Cycle 예측에는 Set A의 Block 고유 특성만 사용한다.
- Position, Initial, 계획일정, Delay는 기존 Scheduling Result에서 조회하는 결과이며 회귀모델 입력값이 아니다.
- 기존 계산 로직과 분석 결과를 임의로 변경하지 않는다.
- 실제 좌표가 없는 야드와 선체 이미지는 개념도라고 명시한다.
- 사용자가 Python을 약 한 달 배운 수준이므로 코드와 설명을 어렵게 만들지 않는다.
- 기존 디자인과 주석, Markdown, 그래프 해석 스타일을 유지한다.
- 수정 후 py_compile과 AppTest를 실행한다.

점검이 끝나면 파일을 바로 대규모로 고치지 말고, 현재 앱이 정상 실행되는지와 발견한 문제만 짧게 보고해줘. 그다음부터 내가 화면 캡처와 수정 요청을 전달하겠다.
